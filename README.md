# ДЗ 2. Конструктор посещения события

Одностраничная карточка события «Ночь в музее»: описание, программа по кнопке и расчёт стоимости дополнительных услуг.
Работа объединяет JSON, HTML/CSS и DOM. Сервер и библиотеки не нужны.

## Запуск

Открыть `index.html` двойным кликом в браузере.

## Что умеет

- Данные события лежат в `app.js` строкой `sourceJson` и разбираются через `JSON.parse()` в `try...catch`.
- Кнопка «Показать программу» открывает блок со временем сбора и начала.
- В форме можно отметить услуги: экскурсия с гидом (500 руб.), аудиогид (350 руб.), каталог выставки (250 руб.).
  После «Рассчитать» показываются количество услуг, итоговая сумма, их названия и JSON-строка отчёта.
- Если ничего не выбрано — «Выберите хотя бы одну услугу.»
- Если JSON повреждён — «Ошибка данных.», форма скрыта.

`buildReport(services, guideChecked, audioChecked, catalogChecked)` отбирает услуги через `filter`,
превращает их в `{ title, price }` через `map` (с `trim()` названия) и считает сумму через `reduce`.
Возвращает `{ count, total, items }`.
